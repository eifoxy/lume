# Referências

**Português (Brasil)** · [English](en/REFERENCES.md)

- Protocolo clássico TC420: [wallneradam/tc420](https://github.com/wallneradam/tc420). Usado como referência do transporte clássico; não comprova compatibilidade com toda variante de firmware.
- Protocolo Pled V2.2 USB/Wi-Fi: análise do executável fornecido durante o desenvolvimento. O binário proprietário não é redistribuído.
- Smart WiFi Timer 3.0, pacote `com.leyview.timercontroller`: [análise estática do APK fornecido pelo usuário](ANALISE-SMART-WIFI-TIMER.md). Confirma respostas `88 00`, identidade nas confirmações e finalização do envio. APK/código decompilado não são redistribuídos.
- [.NET Desktop Runtime 8 — Microsoft](https://dotnet.microsoft.com/en-us/download/dotnet/8.0).
- [Publicação .NET em arquivo único](https://learn.microsoft.com/en-us/dotnet/core/deploying/single-file/overview).
- [Android Network.bindSocket](https://developer.android.com/reference/android/net/Network#bindSocket(java.net.DatagramSocket)).
- [Permissões de rede local no Android](https://developer.android.com/privacy-and-security/local-network-permission).
- [Ferramentas Android](https://developer.android.com/tools).
- [Compatibilidade do Android Gradle Plugin 8.10](https://developer.android.com/build/releases/agp-8-10-0-release-notes).
- [JDK Temurin](https://adoptium.net/).

As referências Android e .NET documentam as plataformas; não são documentação do protocolo proprietário da controladora. Consulte [COMPATIBILIDADE.md](COMPATIBILIDADE.md) para separar resultados de software e validação física.
